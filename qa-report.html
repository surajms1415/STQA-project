4. Defect Management & Root Cause Analysis

Bug ID Severity Priority Category Root Cause & Description Fix Implementation Applied Verification
BUG-001 High P2 - High Calculations IEEE-754 binary floating-point precision leakage in line totals (19.99 * 7 = 139.92999999999998). Quantized financial rounding helper roundMoney() with Number.EPSILON. Resolved
BUG-002 Critical P1 - Critical Quantity Decimal quantities (e.g. 2.5) accepted due to simple num > 0 check. Strict integer verification using Number.isInteger(). Resolved
BUG-003 High P1 - Critical Stock Limits Cart allowed adding items exceeding warehouse stock (3 in cart + 4 added > 5 stock). Cumulative stock bound checks: (currentQty + qty) ≤ stock. Resolved
BUG-004 Critical P1 - Critical Checkout Empty cart checkout allowed, generating $0 invoice and ghost orders. Mandatory non-empty guard clause in processOrder(). Resolved
BUG-005 Medium P3 - Medium Customer Form Whitespace-only names (" ") and letters in phone numbers accepted. String trim and strict regular expression patterns for names and phone digits. Resolved
BUG-006 High P2 - High Payment Security Expired card date (01/20) and 1-digit CVV accepted without calendar comparison. Temporal calendar comparison against current date and strict /^\d{3,4}$/ CVV check. Resolved
