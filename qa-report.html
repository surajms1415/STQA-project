3. Defect Management & Root Cause Analysis

Bug ID Severity Category Root Cause & Description Fix Implementation Applied Verification
BUG-001 High Calculations IEEE-754 binary floating point precision leakage in line totals (19.99 * 7 = 139.92999999999998). Quantized financial rounding helper roundMoney() with Number.EPSILON. Verified
BUG-002 Critical Quantity Decimal quantities (e.g. 2.5) accepted due to simple num > 0 check. Strict integer verification using Number.isInteger(). Verified
BUG-003 High Stock Limits Cart allowed adding items exceeding warehouse stock (3 in cart + 4 added > 5 stock). Cumulative stock bound checks: (currentQty + qty) ≤ stock. Verified
BUG-004 Critical Checkout Empty cart checkout allowed, generating $0 invoice and ghost orders. Mandatory non-empty guard clause in processOrder(). Verified
BUG-005 Medium Customer Form Whitespace-only names (" ") and letters in phone numbers accepted. String trim and strict regular expression patterns for names and phone digits. Verified
BUG-006 High Payment Security Expired card date (01/20) and 1-digit CVV accepted without calendar comparison. Temporal calendar comparison against current date and strict /^\d{3,4}$/ CVV check. Verified
